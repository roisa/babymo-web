How to set on iPhone

  1. 1. Tap Download — the image saves to Photos.
  2. 2. Open Settings → Wallpaper → Add New Wallpaper → Photos.
  3. 3. Choose the wallpaper you just downloaded. Set as lockscreen.

Android: save the image, then Settings → Wallpaper → Gallery.
